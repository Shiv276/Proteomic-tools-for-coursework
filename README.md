# Peptide / Mass Analysis Tool

A small collection of tools I originally made for working with peptide and mass spectrometry data. I've put it online so others can use it without needing to run the code themselves.

Broader documentation is not necessary as the tools are explained on the live app link below. A more extensive explanation of the functions and algorithms may be considered at a later date when I integrate more of the computational tools that I regularly use for bioinformatics.

## Usage:
**Live app:**  
[Open the Streamlit app](https://shiv276-proteomic-tools-for-coursework.streamlit.app)

No installation or Python knowledge is required.

This is not intended to run locally, however it is possible if you clone / download this repository.
